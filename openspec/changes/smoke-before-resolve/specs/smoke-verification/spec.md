# Spec Delta

## Purpose

缺陷修复在置为「已解决」前必须留下针对开发环境的可核验冒烟证据；本能力定义两层冒烟（API / UI）的适用边界、执行契约、证据格式，以及无法覆盖时的豁免与披露要求。

## ADDED Requirements

### Requirement: 冒烟先于解决

缺陷修复的交付顺序 MUST 为「改动 → 发布到开发环境 → 冒烟 → 置为已解决」。未留下冒烟证据的修复 MUST NOT 置为「已解决」。

#### Scenario: 冒烟通过后置为已解决

- **WHEN** 修复已发布到开发环境且其冒烟结果为通过
- **THEN** 允许将 Bug 置为「已解决」，并在解决说明中包含冒烟证据段落

#### Scenario: 冒烟失败

- **WHEN** 冒烟结果为失败
- **THEN** 不得将 Bug 置为「已解决」，改为追加备注记录失败现象、实际输出与失败判据，Bug 保持「处理中」

#### Scenario: 未跑冒烟

- **WHEN** 修复已发布但未执行任何一层冒烟，也未声明豁免
- **THEN** 不得将 Bug 置为「已解决」

### Requirement: 冒烟目标必须是开发环境

冒烟 MUST 针对已部署修复的开发环境执行，MUST NOT 以本地开发服务器或纯静态检查替代。本地或源码级验证成功不能作为冒烟证据。

#### Scenario: 本地验证通过但环境未验证

- **WHEN** 仅在本地启动 dev server 或仅通过编译、单测、语法检查
- **THEN** 该结果 MUST NOT 计为冒烟证据

#### Scenario: 冒烟针对既有环境

- **WHEN** 执行任一层冒烟
- **THEN** 目标是修复实际部署所在的开发环境地址，而非临时启动的本地服务

### Requirement: 两层冒烟的适用边界

冒烟分为接口层与界面层。接口层验证数据、接口返回与状态流转；界面层验证用户可见的交互与渲染。可按缺陷性质选择，但界面类缺陷 MUST NOT 仅以接口层替代。

#### Scenario: 缺陷为界面交互问题

- **WHEN** 缺陷表现为点击、切换、弹窗、渲染等用户可见行为异常
- **THEN** MUST 有界面层冒烟证据

#### Scenario: 缺陷为数据或接口问题

- **WHEN** 缺陷表现为数据错误、接口返回异常或状态流转错误，且不依赖界面呈现
- **THEN** 接口层冒烟证据 SHALL 满足要求

#### Scenario: 两层皆不适用

- **WHEN** 缺陷既无法通过接口复现，也无法通过界面复现
- **THEN** 允许声明豁免，但 MUST 满足豁免披露要求

### Requirement: 界面层冒烟需先确认新版本可见

界面层冒烟依赖宿主加载已发布的最新产物。执行前 MUST 确认环境中可见的版本与本次发布版本一致；不一致时 MUST NOT 开始断言。

#### Scenario: 环境版本滞后

- **WHEN** 环境中可见的产物版本与本次发布版本不一致
- **THEN** MUST NOT 据此产出通过结论，需等待新版本可见后重试，或按无法覆盖处理并说明

#### Scenario: 测到旧产物

- **WHEN** 界面层冒烟作用于发布前的旧产物
- **THEN** 其结果无效，MUST NOT 作为冒烟证据

### Requirement: 冒烟证据格式

解决说明中的冒烟证据 MUST 包含固定字段：冒烟类型、目标地址、场景描述、结果、证据引用。字段取值受限，结果 SHALL 仅允许通过与失败两种。

#### Scenario: 提交通过证据

- **WHEN** 冒烟结果为通过
- **THEN** 证据段落包含类型、目标、场景、结果与可供复核的证据引用（命令与关键响应片段，或截图与日志路径）

#### Scenario: 证据缺少必要字段

- **WHEN** 证据段落缺少类型、目标、场景、结果或证据引用中的任一项
- **THEN** SHALL 视为未提供有效冒烟证据

### Requirement: 无法覆盖时的豁免披露

无法执行冒烟时 MUST 显式声明豁免，并说明未覆盖原因与所采用的替代验证；MUST NOT 沉默跳过，也 MUST NOT 以笼统表述代替具体原因。

#### Scenario: 界面无法在当前环境直达

- **WHEN** 缺陷所涉界面只能经宿主内特定入口到达，无法用独立地址驱动
- **THEN** 声明豁免，原因归属「界面在宿主内无法直达」，并说明替代验证

#### Scenario: 依赖特定环境数据

- **WHEN** 复现需要特定租户、账号或数据状态而环境不具备
- **THEN** 声明豁免，原因归属「需要特定环境数据」，并说明替代验证

#### Scenario: 仅偶发不可稳定复现

- **WHEN** 缺陷现象无法稳定重现
- **THEN** 声明豁免，原因归属「不可稳定复现」，并说明已尝试的复现手段

#### Scenario: 豁免缺少替代验证

- **WHEN** 声明豁免但未说明任何替代验证
- **THEN** SHALL 视为未提供有效冒烟证据
